# Code of Conduct

## Our commitment

The AI Trip Planner project aims to maintain a respectful, inclusive, and constructive environment for people contributing across different backgrounds and experience levels.

## Expected behavior

Participants are expected to:
- communicate respectfully and professionally;
- explain disagreements with evidence and clear reasoning;
- provide actionable feedback on code and documentation;
- accept good-faith corrections;
- respect privacy, licensing, and intellectual property;
- keep discussions focused on the repository;
- use synthetic data in examples and reports;
- protect credentials and user travel information.

## Unacceptable behavior

Examples of unacceptable conduct include:
- harassment, discrimination, threats, or intimidation;
- personal attacks, insults, or deliberate humiliation;
- doxxing or disclosure of private information;
- publishing credentials, access tokens, or private user itineraries;
- persistent disruption of issue and review discussions;
- knowingly submitting malicious changes or deceptive claims.

## Scope

This code applies to repository issues, pull requests, reviews, discussions, and other communication directly associated with the project.

## Reporting

Report conduct concerns privately to **Brajesh Kumar** ([ @Brajesh31 ](https://github.com/Brajesh31)) through GitHub. Include relevant context and links. Do not publish private information in public issues.

Reports will be reviewed as fairly and discreetly as possible. The maintainer may request clarification, remove inappropriate content, close discussions, or restrict participation when necessary to protect the project community.

## Maintainer responsibility

The maintainer is responsible for clarifying expectations and applying this code consistently. Decisions should focus on observable behavior and impact on project participation.

## Attribution

This is a project-specific code of conduct written for this repository.
